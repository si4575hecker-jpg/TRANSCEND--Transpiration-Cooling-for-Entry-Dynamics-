UNRELIABLE

This was a simulation that ended up being highly unreliable due to wrong values. This is the simulation that removed skipping and set the alpha to 60°. This helped by increasing surface area, therefore increasing drag, thereafter decreasing heat flux and required coolant. These 2 technologies would stick with us all the way till the end, so they are very very important and valuable.

RELIABLE
The unreliable simulation was debugged and improved in this simulation. This showed how the spacecraft still got lifted upwards by around 10 meters due to immense drag. This would later be fixed an new technologies would be added. Still, this simulation requiered high amounts of coolant and the temparature values were still broken.

This is why this simulation was rejected due to inconsistant and unreliable data.
